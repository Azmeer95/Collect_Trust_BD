# CollectTrust BD — Problem Note

In Bangladesh, shared money collections are still often handled manually through WhatsApp/Messenger, MFS screenshots, phone numbers, Excel sheets, and verbal trust. This creates reconciliation problems for collectors and anxiety for members.

The MVP helps a collector create a collection, add members, track expected payment amounts, accept mock payment proof, and show transparent status to everyone.

This is a demo-only fintech simulation. It does not collect real NID, does not process real payments, and does not integrate with live bKash/Nagad APIs.
