# CollectTrust BD — User Flow

## Day 1 Collector Flow

1. User opens Landing Page
2. User clicks Login or Start Demo
3. User reaches Login Page
4. User logs in as collector
5. User lands on Dashboard
6. User sees collection stats and active collections
7. User clicks Create Collection
8. User fills collection form and submits
9. User lands on Collection Detail page
10. User sees member statuses for that collection
11. User can open Member List to view all members in the group

## Day 1 Navigation Map

Landing Page → Login → Dashboard → Create Collection → Collection Detail → Member List
